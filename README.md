# Histórias do Caldeira — primeiro site funcional

Este pacote contém uma primeira versão estática e responsiva do site.

## Arquivos

- `index.html` — estrutura do site.
- `styles.css` — visual e adaptação para celular.
- `script.js` — navegação, leitor de HQ e estatísticas locais.

## Como testar

Abra o arquivo `index.html` no navegador.

## Estatísticas

A primeira versão registra estatísticas no `localStorage` do navegador, então os números são locais a este navegador/dispositivo.

Para ter um contador real e global, com todos os visitantes do site somados, a próxima etapa é conectar um serviço de analytics/banco de dados. A estrutura do site já está preparada para isso.

## Publicação

O projeto pode ser publicado em serviços de hospedagem estática como GitHub Pages ou Cloudflare Pages.

## Próxima etapa recomendada

1. Substituir os exemplos pelas páginas reais das HQs.
2. Adicionar as capas e fotos reais.
3. Conectar analytics global.
4. Publicar.
5. Opcionalmente registrar um domínio próprio, como historiasdocaldeira.com.br.
